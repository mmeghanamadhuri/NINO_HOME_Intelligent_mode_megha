## Voice / conversation fixes

Committed as `00f528d` — *fixed embeddings errors from DB TTS pipeline* (main server code changes below).

### 1. Reject non-English / junk STT

**Problem:** Short noise clips were misheard by ElevenLabs as Telugu (e.g. `పాకుండాయి`), sent to the LLM, and produced useless long TTS.

**Fix (`memory_filters.py`):** treat STT as unintelligible when most letters are non-Latin → existing `stt_rejected` path (“Sorry, I didn't catch that…”) instead of calling the LLM.

### 2. Startup greeting — stop speaking markdown / list junk

**Problem:** Phase C summaries like:

```text
### Summary
1. User learned about …
```

leaked into spoken greetings as *“Yesterday we discussed ### Summary”* or *“…discussed 1…”*.

**Fix (`llm_service.py` — `parse_summary_topics_for_greeting`):**

- Strip markdown headings (`### …`) and section labels (`Summary`, etc.).
- Strip numbered-list markers (`1.`, `2)`, …).
- Reject junk topics that are only a number / `topic 1`.

### 3. Time-of-day greetings from PC clock

**Problem:** User said “good morning” in the evening; bot echoed “good morning”.

**Fix:**

- `alarm_time.py`: `day_part()` / `day_part_greeting()` from local PC clock  
  - 05–11 → Good morning  
  - 12–16 → Good afternoon  
  - 17–21 → Good evening  
  - later → Good evening (not “good night” as a hello)
- `voice_service.py`: short greetings (`hi` / `good morning` / …) answered with the **current** period, not the user’s wording.
- `llm_service.py`: inject current local time + day-part into the voice prompt so the LLM does not echo a wrong greeting.

### 4. Warmer smalltalk (less helpdesk)

**Problem:** After “I am great”, bot replied with *“How can I assist you today?”*; face flicker also dropped viewer context on continue-listen.

**Fix:**

- Dedicated paths for “how are you?” and wellbeing replies (“I am great”, etc.) — warm, chatty, no assist-me phrases.
- `query_needs_recent_context` treats short wellbeing replies as follow-ups so prior turn stays in context.
- LLM style rules: sound like a friendly housemate; ban service-desk phrasing.
- `app.py`: if face briefly drops during continue-listen, recall last voice viewer so chat continuity is kept.
- Continue-listen reply paths extended with `greeting` and `smalltalk`.

2. Face greet → spoken yesterday-topic should be a real subject (not `### Summary` or `1`).
